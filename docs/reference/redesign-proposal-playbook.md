# The redesign-proposal playbook (superseded)

The redesign process now lives in the
[`qm-redesign-review`](../../.claude/skills/qm-redesign-review/SKILL.md) skill, the single entry
point for any "redesign X", "polish X" or "apply the design language to X" request. It produces a
published Artifact (measured findings, a working mock, a before/after, the change table) that the
user approves before any component is written; the build then runs on the normal
[change flow](./change-workflow.md).

This playbook's requirements (verbatim tokens, shipped geometry, every real state, the evidence
list, the re-authoring test, reframe-first presentation) were folded into that skill on 2026-09-26.

The approach was approved on 2026-08-21 (Custom SIM Profiles, `/cellular/custom-profiles`)
and the user asked for it to be the reference basis for subsequent redesigns.
