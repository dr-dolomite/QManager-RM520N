## Items
1. **`useModemStatus` 2 s default.** Hook default 2 s → 5 s (just over one poller cycle, ~3.7-4 s; faster
   re-reads the same snapshot). 10 s cap and visibility pause unchanged, so the heartbeat contract holds.
   Per page at 17.5 ms/fetch: 2 s = 0.88 pts, 5 s = 0.35, 10 s = 0.18. Caller overrides approved by PM.
   Tier check: `AP_ACTIVE_GRACE=20` (`qmanager_poller:59`); worst heartbeat age at 10 s polling ≈ 10 s +
   one ~4 s cycle ≈ 14 s < 20 s (T6.2 measured `active` 12/12 samples at 10 s).

   | page (caller) | before | after |
   |---|---:|---:|
   | antenna alignment (`antenna-alignment.tsx`) | 2 s | 2 s (`STATUS_POLL_FAST_MS`) |
   | antenna statistics, cellular info, band / frequency / tower locking, APN, probe targets, quality thresholds | 2 s | 5 s (default) |
   | cellular settings, network priority, custom profiles, onboarding band step | 2 s | 10 s (`STATUS_POLL_SLOW_MS`) |
   | dashboard, watchdog, latency monitoring, scanner, SIM-swap banner, sidebar | explicit | unchanged |

   The shared store runs at the minimum of mounted callers, so the always-mounted banner/sidebar (10 s)
   never slow a page down.
2. **lighttpd keep-alive.** Idle timeout measured 5 s (a second request on one TLS connection is answered
   after a 4 s gap, not after 6 s or 20 s). Full TLS connection = 20.0 ms lighttpd own CPU per call vs 2.5 ms
   on a reused connection → ≈ 17.5 ms per handshake (curl, no session resumption: upper bound). The
   dashboard's streams (5.25 s / 10 s / 30 s) all exceed 5 s, so a browser likely re-handshakes on most
   requests: ≤ 0.62 req/s × 17.5 ms ≈ 1.1 pts upper bound. Proposal for the installer owner:
   `server.max-keep-alive-idle = 30` in `scripts/usrdata/qmanager/lighttpd.conf` (installer-managed,
   lighttpd 1.4.82). Not written.
3. **One-shot CGIs.** `settings.sh` GET: one `jq` for all keys, `set --` for the tz fields.
   Body identical for the real config and 25 of 35 edge configs (verifier); forks 57 → 15; CPU 276 → 83 ms
   per call. Differs only on odd values: hostname `-n`/`-e` (reachable via POST; old `echo` swallowed it,
   new returns it), trailing newlines, object/array values, two-document files, days `"1
2"` (old sent no
   body). Accepted as fixes. `about.sh`: CPU is the two public-IP
   `curl` calls (102.5 ms CPU each, measured); a fork cut (38 → 20) did not move CPU (182 → 207 ms, noise),
   so it was reverted. Real cut = cache the public IP (follow-up, design change).
4. **`qlog.sh` under `set -u`.** `${…:-}` on `_QLOG_LOADED` and positional args. Old: `sh -u` "parameter not
   set", `bash -u` "unbound variable" at line 28; new: loads and logs under both.
5. **Heartbeat symlink.** `[ -L f ] || echo $$ > f` (builtin, no fork) in `fetch_data.sh` and
   `overview.sh`. Device: `fs.protected_symlinks=1`, which already blocks www-data from following a link
   owned by another non-root user; the test closes the remaining case and is defence in depth. Scratch-copy
   test: planted link's target untouched; normal write still www-data-owned. Residue: the
   health check's `stat -c %U` reads a link's owner (out of set).
6. **Ping-history cut / hidden tab.** Full archive (1.16 MB today) 426 ms CGI + 110 ms lighttpd own per call
   vs `?last=400` 50.5 + 24 ms: −86 % CPU per call, at 1/30 s ≈ 1.8 → 0.25 pts (CGI + lighttpd own). Hidden tab on the device:
   not run (needs a logged-in browser on the device UI; T6.2's verifier measured 0 requests in 38 s hidden
   on a dev build).
