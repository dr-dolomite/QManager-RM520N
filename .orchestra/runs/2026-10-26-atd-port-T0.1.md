# T0.1 — Device feasibility probe (Phase 0)

## Goal
Measure, on the live modems, whether the RM551E broker's three lanes (AT, QMI, data-call) can run on
the RM520N-GL, and record the facts the platform deltas D2–D7, D12 and D15 depend on. Output is
evidence, not a recommendation; the lead writes the GO/NO-GO.

## Context (read only what you need)
- Parent roadmap: `.orchestra/runs/2026-10-26-atd-poller-port.md` — the Platform deltas table.
- RM551E broker (sibling repo, read-only): `D:\Projects\QM PROJECT\QManager\docs\features\at-broker.md`,
  `docs\features\qmi-lane.md`, `native\qmanager_atd\src\qmi\transport.rs`, `src\at\channel.rs`.
- The vendored copy in this repo: `native/qmanager_atd/`.
- Decisions already taken: `atcli_smd11` and `sms_tool` will be dropped; no decompiling, no REA.

## Devices and access
- Use the **modem bridge** MCP: `mcp__modem__*` = RM520N-GL, `mcp__modem-rg501q__*` = RG501Q-EU
  (`modem_exec`, `modem_read`, `modem_write`, `modem_ps`). Read `docs/reference/modem-bridge.md`
  first. The bridge checks the serial on connect (RM520N `61368cd2`, RG501Q `b7e3d6f1`); still print
  `cat /etc/quectel-project-version` at the top of each capture.
- RM520N-GL is at `RM520N_IP` (192.168.225.1), reachable 2026-10-26. Probe the RG501Q-EU only if
  its bridge connects; otherwise record "offline".
- Fallback only if the bridge is unavailable: Posh-SSH (`New-SSHSession -Force`), creds from `.env`;
  never echo `.env` values.

## Rules
- Read-only. No config writes, no service restarts, no AT set commands, no reboots. AT queries only
  through `qcmd` (e.g. `ATI`), except the one bounded test in Q4.
- First, clean up after the stopped r2 run: `/tmp/t01_probe.sh` and `/tmp/t01_known.*` on the
  RM520N are ours; remove them if still there, and confirm no `t01_probe.sh` process remains.
- Any probe script you upload goes to `/tmp` and is removed when you finish.
- Do not edit any tracked file and commit nothing. Write captures to
  `.orchestra/scratch/atd-T0.1-<device>.txt` and the report to `.orchestra/scratch/atd-T0.1-report.md`
  (both gitignored).

## Questions (answer each with the command and its trimmed output)
1. **Runtime:** `uname -a`; libc (`ls -l /lib/ld-* /lib/libc*`); `/proc/cpuinfo` features; `free`;
   `df -h /usrdata /opt /tmp`.
2. **QRTR (D6):** `grep -i qrtr /proc/net/protocols`; `zcat /proc/config.gz | grep -i QRTR`
   (if present); `grep -i qrtr /proc/kallsyms | head`; `ls /proc/net | grep -i qrtr`. Can a
   family-42 socket be opened (a tiny static test, or the protocols table)? Is a QRTR name service
   published, and which services, if any on-device tool can list them?
3. **QMI holders (D6):** which processes hold QRTR or QMI sockets/nodes: `ls -l /proc/*/fd` matched
   against `/proc/net/*` socket inodes; `ps` for Quectel/Qualcomm daemons (`QCMAP_ConnectionManager`,
   `netmgrd`, `qti`, `ql_*`, `atfwd`); `ls -l /dev/smd* /dev/glink* /dev/cdc-wdm* /dev/qcqmi*`. If a
   holder cannot be attributed, write "could not attribute" with what was seen.
4. **smd11 multi-opener (D12), bounded:** hold `/dev/smd11` open read-write and idle for at most 20 s
   (`exec 3<>/dev/smd11; sleep 20; exec 3>&-`); never read or write fd 3. During the hold run
   `qcmd ATI` and one read-only `sms_tool` verb (the one `scripts/usr/lib/qmanager/sms_alerts.sh`
   uses for status), twice each. Report whether each answered normally. If the first `qcmd ATI`
   fails, close fd 3 at once and stop this test.
5. **Permissions (D2, D3, D4, D15):** `sysctl fs.protected_regular fs.protected_fifos`;
   `stat -c '%U:%G %a %F' /tmp/qmanager_at.lock /tmp/qmanager_long_running /dev/smd11`;
   `ls -ld /tmp /var/run /run /var/lock`; `id www-data`. As root, does
   `sh -c 'exec 3>>/tmp/qmanager_at.lock'` succeed (exit code)? It appends nothing.
6. **Data-call interfaces (D7):** `ls /sys/class/net`; `cat /proc/net/route`; whether `rmnet_ipa0`
   and `rmnet_data<N>` exist and which carries the default route.
7. **Current AT owner:** `pgrep -fa qmanager`; `systemctl is-active qmanager-poller`; who holds
   `/dev/smd11` right now (fd scan).

## Done when

opens with one status line (DONE / DONE_WITH_CONCERNS / BLOCKED), then per question the evidence,
then "still unknown", then "device touched: read-only probes only / other (say what)".
