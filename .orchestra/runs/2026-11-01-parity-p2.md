## Proposed RELEASE_NOTES bullets (for the lead)
## ✨ New Features

- **Suggested APNs for your SIM.** On **Cellular → Settings → APN Management**, the APN field now offers the known internet APNs for the SIM in the modem; pick one and the APN (and its IP protocol, when the carrier lists one) fills in, then Save as usual. (Matched by the SIM's home network from its IMSI against a bundled list of about 800 networks built from LineageOS APN data; typing your own APN still works.)

## 🛠️ Improvements

- **A redesigned Band Locking page.** **Cellular → Band Locking** opens on a status card showing the carriers on air and how each band category is locked, with Band Failover as an Off/On switch and its state chip beside it. Cards owned by a SIM profile now say "Profile controlled", and the scenario banner links to Custom Profiles, where scenarios are changed. (Layout ported from RM551E v0.1.34; NR-DC band locking is not included.)
- **A redesigned Tower Locking page.** **Cellular → Tower Locking** now lets you lock, add or remove a cell straight from its carrier tile, and the failover threshold has a slider beside its number field with a live 20-bar signal meter. Each change shows one clear message, including a warning when the setting saved but did not fully take. (Keep after reboot stays a single switch for both radios, because the modem stores it as one setting.)
- **A redesigned Custom Profiles page.** **Cellular → Custom Profiles** lists your profiles with an Active / SIM Mismatch / Inactive chip, and creating or editing one opens a four-step wizard. Applying a profile made for a different SIM now asks first, and a profile for the SIM in the modem applies right away. (Scenarios are added and edited in one dialog, the running scenario pulses, and ICCIDs are compared with the trailing filler digit ignored.)
- **Tidier Settings and IMEI buttons.** **Cellular → Settings** and the APN card get a compact Refresh button, and **IMEI Settings** gets a Reset button and a check mark (tap the info icon for what it means) when the field already matches the modem's IMEI. Choosing "Reboot later" after an IMEI change now keeps the reboot reminder banner on every page until you restart.

## 🐛 Fixes

- **Reverting to the carrier APN no longer fails silently.** "Use carrier default" on the APN card now completes cleanly, and if the modem changed but QManager could not save the setting, you get a warning instead of a quiet success. (`apn.sh` no longer leaves a stray temp file when a save fails, and falls back to removing the saved APN file so it reads as carrier default.)
- **Clearer APN error messages.** When an APN change fails, the message now says what went wrong — the modem could not detach, did not confirm it re-registered, was given a different APN, or another APN change was still running — in all five languages. (Eight `apn.sh` error codes now have translated text.)
