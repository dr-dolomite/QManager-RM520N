## Proposed RELEASE_NOTES bullets
### ✨ New Features
- **Device Access page.** System Settings → Device Access holds a Passwords card with Web and SSH tabs; each asks for
  its current password first, and the SSH tab now checks the real root password. (Root check runs through the
  `qmanager_set_ssh_password --verify` helper; wrong guesses share the sign-in lockout and show attempts left.)
- **Debug Report.** System Settings → System Health Check has a one-click download of a plain-text snapshot to share
  when troubleshooting. (Runs as www-data from an allowlist; IMEI, IMSI, ICCID and phone numbers are masked.)

- **System Settings matches RM551E.** Two cards: Device & Units (with Tracked SIMs and a Discard button) and Scheduled
  Reboot, which now shows the modem's live clock and a day rail.
- **Stuck installs are caught.** Software Update notices when an install goes quiet for two minutes and offers a
  confirmed Restart now; failure toasts now say why.
