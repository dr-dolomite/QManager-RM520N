# T0.2 — Value baseline on the real AT transport (Phase 0)
parent: `.orchestra/runs/2026-10-26-atd-poller-port.md`   seat: independent Opus session   rev: r1   opened: 2026-10-26

## Goal
Measure what today's AT transport costs on the RM520N-GL, so the broker GO/NO-GO (gate G1) compares
the broker against real numbers. The broker's claimed win is removing the per-command
`atcli_smd11` spawn and the lock contention around it; measure exactly those. Evidence only, no
recommendation.

## Context (read only what you need)
- Parent roadmap: "Value case" section and the T0.1 result section.
- `docs/reference/poller-cpu-profile.md` — method and the htop trap: child CPU lands in
  `cutime`/`cstime` (fields 16–17 of `/proc/<pid>/stat`), not in htop. Its baseline replaced `qcmd`
  with a replay stub, so it does NOT include the transport cost; that gap is why this ticket exists.
- `scripts/usr/bin/qcmd` (lock `/tmp/qmanager_at.lock`, held read-only via `9<`; `flock -x -n`
  retry loop — BusyBox `flock` has no `-w`), `scripts/usr/bin/qmanager_poller` (`qcmd_exec`).
- Device facts: bash 3.2 has no ms clock and `date +%s%N` prints a literal `%N`. Use bash's `time`
  keyword, `/proc/uptime`, or `/proc/<pid>/stat` deltas (USER_HZ = `getconf CLK_TCK`, usually 100).

## Device and access
RM520N-GL only, through the modem bridge (`mcp__modem__*`; read `docs/reference/modem-bridge.md`).
RG501Q-EU is out of scope for this ticket.

## Rules
- Read-only. No restarts, config writes, AT set commands, or reboots. The poller keeps running
  throughout — the baseline is the system as users run it.
- AT traffic is query-only: `AT`, `ATI`, and the poller's own queries. Space loops ≥ 0.5 s apart
  so the poller is never starved for longer than one of its own cycles.
- Direct `atcli_smd11` calls must take `/tmp/qmanager_at.lock` exactly as `qcmd` does (read-only
  open + `flock -x -n` retry), never bare.
- **SMS:** `sms_tool status` only. Never `recv`, `delete`, `send`, `at`, or the `cellular/sms.sh`
  GET — an inbox read issues `AT+CMGL=4`, which marks every message read. The inbox-read cost comes
  from the 2026-09-07 measurement (~6.8 s lock hold), quoted as such.
- Probe scripts go to `/tmp` and are removed at the end. Edit no tracked file, commit nothing.
  Write captures to `.orchestra/scratch/atd-T0.2-rm520n.txt`, report to
  `.orchestra/scratch/atd-T0.2-report.md`.

## Measurements
1. **Per-command cost.** 20× `qcmd AT` and 20× locked `atcli_smd11 AT`: wall time per call
   (median, p90, max) and CPU per call (from the measuring shell's `cutime+cstime` delta over the
   loop). Also 20× `/bin/true` for the fork floor, so the transport's own share is visible.
2. **Lock occupancy.** For 120 s, sample every 0.1 s whether `/tmp/qmanager_at.lock` is held (a
   read-only open + `flock -x -n` that releases at once; count only, hold nothing). Report the busy
   fraction and the longest busy run. Note any CGI or UI activity seen during the window (`ps`).
3. **Lock wait as seen by a caller.** 30× `qcmd 'AT+CSQ'` spaced 2 s apart: wall time, and how many
   returned `modem_busy`.
4. **Poller on the real transport.** Over 300 s: poller `utime+stime+cutime+cstime` delta, number of
   cycles (count `/tmp/qmanager_status.json` mtime changes or its timestamp field), and system
   `/proc/stat` busy %. Derive CPU per cycle and the poller's share of the one core. Count the
   `qcmd` calls per cycle from the code (`qcmd_exec` sites per tier) and multiply by item 1 to give
   the transport's estimated share of poller CPU.
5. **SMS status cost.** 10× locked `sms_tool -s ME status` (same lock discipline as `sms.sh`): wall
   time and CPU per call.
6. **Idle footprint.** `free`, poller RSS (`/proc/<pid>/status` VmRSS), and the RSS of one
   `atcli_smd11` if catchable — the budget a resident broker would replace.

## Done when
Every measurement has numbers with the command that produced them, or "could not measure: <reason>".
The report opens with one status line (DONE / DONE_WITH_CONCERNS / BLOCKED), then a summary table
(metric, value, method), then details, then "still unknown", then "device touched".

## Out of scope
Building or running the broker (T0.3), any GO/NO-GO call, RG501Q-EU, any repo change.
