### Item 2 — boot auto-apply attach cycle on the RG501Q-EU
- `qmanager_profile_apply:760-777`: a failed `AT+CGCONTRDP` read skips; a bare `OK` (no bearer) proceeds to `apn_apply_write` (COPS=2 → write → COPS=0). Documented on purpose in `sim-profiles.md:214`: bare OK "is the wrong-APN case the step exists to fix".
- RM520N-GL this boot (08:31:20): bearer already up, APN step skipped (`done=2, skipped=2`), no COPS. So the cycle fires only when the bearer is not up at apply time.
- RG501Q-EU now: `+CEREG: 0,0`, `+C5GREG: 0,0` (not registered), `CGDCONT` CID 1 = `internet` (the right APN). The S5 boot (Nov 2 00:22) log has rotated out; S5 recorded a bare OK and a COPS cycle at 00:22:41.
- When there is no bearer but `AT+CGDCONT?` already holds the profile's APN, the cycle rewrites the same value and forces a detach/re-attach. That restarts the network search on a modem that is still trying to register, and drops eth0 for ~4 s. The "self-concealing CGDCONT" concern (`:744`) only applies when a bearer exists (a stale bearer behind a matching CGDCONT); with no bearer, the next attach uses the CGDCONT value anyway.

### Item 3 — sms-forward `failed` once after OTA from v0.1.14
**Already fixed on development by R5 (merged 9400643f, ancestor of 69604a63).** Root cause (R5 notes): the v0.1.14–v0.1.17 daemon's `trap '…' EXIT INT TERM` has no `exit`, so BusyBox ash keeps running after TERM; the batched `systemctl stop` waited 90 s, SIGKILLed, and left `Result=timeout` → `failed` until reboot (it recovered on the next boot). Fix in place: `install_rm520n.sh:1566-1567` and `uninstall_rm520n.sh:214-215` queue `--no-block stop` and then `systemctl kill -s KILL`; `reset-failed` over the units (`install_rm520n.sh:1616`, `uninstall_rm520n.sh:219`); the new daemon traps `exit 0`; the unit has `TimeoutStopSec=10`. OTA runs the same installer (`qmanager_update:275`), so lockstep holds. R5 proof (d): the stop took ~1 s, `Result=success`, no failed units after boot (RM520N-GL). Not proven: an OTA that starts from v0.1.14 itself (needs a rollback + reinstall).
